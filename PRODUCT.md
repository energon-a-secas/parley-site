# Parley: product one-pager

**What it is:** A catalog of chat and assistant UI patterns observed in shipping products, each with a build spec, dated evidence, pitfalls, a live demo and original reference code in plain HTML, CSS and JS.

**Who it is for:** Someone about to build or brief a chat interface (a developer, or a developer directing a coding agent) who does not want to rediscover how ChatGPT, Claude, Perplexity or Intercom solved the composer, the stream, the tool cards and the shell.

**Register:** product (a tool someone uses), not brand (a page someone visits).

**The scene:** Late in a build session, a second monitor, the prompt "add a chat panel" half written. The person opens Parley, filters to Composer, reads the pitfalls, copies the agent brief and pastes it into the prompt. Dark by default because that is where the session already is; the demo flips to light to check the pattern survives both.

**What done looks like:** One pattern copied out, as a brief or a file, and the person back in their own project within two minutes.
